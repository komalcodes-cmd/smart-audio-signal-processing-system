🎵 Smart Audio Signal Processing Studio

Smart Audio Signal Processing Studio is a Python-based desktop application developed to record, upload, process, and analyze audio signals. It uses Digital Signal Processing (DSP) techniques to reduce background noise and improve audio quality.

The application provides an interactive GUI where users can upload audio files, apply digital filters, visualize waveforms, and compare original and processed audio signals.

✨ Features

- Upload and process audio files.
- Reduce unwanted background noise.
- Apply Low-Pass Filtering.
- Visualize audio waveforms.
- Compare original and filtered audio.
- Record and play audio.
- Simple and user-friendly GUI.

🛠️ Technologies Used

- Python
- Tkinter
- NumPy
- SciPy
- SoundFile
- SoundDevice
- Matplotlib

🎯 Project Objective

To demonstrate practical applications of Digital Signal Processing by developing an interactive tool for audio filtering, noise reduction, and signal visualization.

💡 Applications

- Audio enhancement
- Noise reduction
- Sound analysis
- Digital audio processing
- Educational DSP experiments
